# 生活助理

[English](README.en.md)

一个跑在 AI agent 里的个人生活助理。你随口说，它帮你拆分、归档、提醒，在你问"现在干嘛"的时候给你一个答案。

为 ADHD 式的生活设计：点子多、精力起伏大、计划常常要临时改。

不绑定任何一个 AI 工具。Claude Code、Gemini、Antigravity、Codex 等能读写文件的 agent 都可以用。

> **给 AI 的说明**：如果你是读到这个文件夹的 AI agent，还没有 `agent-setup.md` 的话，先按 `INSTALL.md` 安装；装好后的全部规则在 `AGENTS.md`。这份 README 是给人看的介绍。

## 亮点

- **说人话就行。** "今天想洗衣服，下午买菜，周六前一定要看完那部电影。" 它会拆成几条，分好"必须、打算、有空"，放进今天、本周或点子库。
- **不确定的才问。** 收录时只把拿不准的地方标出来问你，最多三个。回一个"好"就存。
- **现在干嘛，只给一件。** 不甩一长串清单给你。想看全部再说。
- **计划可以随时缩水。** 说一句"今天不行了"，它只留一件最要紧的，其余自动往后挪，不追问原因。
- **推不动的事会被注意到。** 同一件事挪了三次，它会问你要不要拆小、降级或者放弃。
- **点子不会丢，也不会逼你。** 没想好什么时候做的，进点子库。周回顾时偶尔翻出来问问你。
- **四层目标。** 年、季度、月、本周，想规划时随时说，它帮你理清层级，再拆成能马上开始的任务。
- **五分钟周回顾。** 做了多少、哪些一直在推、习惯和目标进展如何，然后一起定下周重点。到了月底、季末自动顺带回顾。
- **学技能有专门的档案。** 学拳击、学画画、学写小说，各有一个档案：什么时候开始的、每次练了什么、定期复盘时学到了哪一步。复盘默认每月一次，可以按技能单独调，只在对话里提，不会塞进日历。
- **长期项目有专门的档案。** 写小说、做 app、设计桌游，每个项目一个档案：下一步、里程碑、进展记录、笔记。可以用一个数字追踪进度，比如字数。两周没动的会提醒你。
- **完成一次，自动分发。** 说"看完了"，它会同时记进日志、体验记录；说"健身了"，顺便打卡。
- **提醒到手机。** 连上 Google 日历后，有具体时间的任务、有截止日的必须任务，会自动建日历提醒，不用你开口。
- **中英文都能用。** 第一次选语言，之后也能随时切换。数据文件只用一套写法存，不会中英混杂。
- **数据全是你的。** 所有内容都是文件夹里的纯文本，能打开、能改、能带走。换一个 AI 工具也照样能用。

## 快速开始

1. 准备一个能读写本地文件的 AI agent，比如 Claude Code、Gemini CLI、Antigravity、Codex。
2. 在这个文件夹里启动它。
3. 对它说：**"读 INSTALL.md，帮我装好。"**
   它会自己判断怎么接上这套规则和技能，然后让你选语言：English、中文，或者自动跟随。
4. 如果它让你重启，就退出再重新打开一次。
5. 打个招呼，比如"在吗"。它会告诉你可以怎么用。

以后每次都要在这个文件夹里启动 agent，否则它读不到规则和数据。

## 可以这样跟它说

| 你说 | 它做 |
|---|---|
| 一堆要做、想做的事，越乱越好 | 拆分、分类、给你确认 |
| 现在干嘛 | 根据时间建议一件事 |
| 今天要干嘛 / 这周有什么 / 全部 | 按时间范围列出来 |
| 交房租了 / 看完了 / 今天健身了 | 记录完成，自动分发 |
| 今天不行了 | 只留一件，其余往后挪 |
| 我想规划一下 / 这个月想做到 | 整理成四层目标 |
| 回顾 | 周回顾，定下周重点 |
| 开始学拳击 / 今天练了拳击 | 建学习档案 / 记一次练习 |
| 复盘拳击 / 学得怎么样 | 回顾进度 / 看学习曲线 |
| 拳击改成每两周复盘 | 调整复盘频率 |
| 开始写小说 / 小说今天写了 2000 字 | 建项目档案 / 记一次进展 |
| 小说下一步做什么 / 我的项目 | 看下一步 / 看所有项目进度 |
| 同步日历 | 检查并补齐日历提醒 |
| 以后说英文 / 自动跟随 | 切换回复语言 |
| 把数据转成英文 | 把全部数据改成英文写法 |

## 文件说明

刚下载时只有这几样：

| 文件 | 内容 |
|---|---|
| `README.md` / `README.en.md` | 这份说明 |
| `INSTALL.md` | 给 AI 看的安装说明 |
| `AGENTS.md` | 助理的全部规则，相当于大脑 |
| `config.md` | 个人设置：语言、回顾日、日历、个人风格 |
| `.agents/` | 技能和空白模板。隐藏文件夹，一般不用管 |

装好、选完语言后会多出来：

| 文件 | 内容 |
|---|---|
| `tasks.md` | 进行中的任务 |
| `goals.md` | 四层目标 |
| `ideas.md` | 点子库 |
| `experiences.md` | 想体验和已体验的书、电影、剧、专辑、演出、城市 |
| `habits.md` | 习惯定义和打卡 |
| `journal/` | 每月一个文件，记录完成的事和周回顾 |
| `learning/` | 正在学的技能，一个技能一个档案 |
| `projects/` | 长期项目，一个项目一个档案 |
| `state.md` | 系统状态，不用管 |
| `agent-setup.md` | 安装记录：用的哪个 agent、改了什么 |

用了一段时间后还会出现 `goals-archive.md`，存放过去的目标和结果。

另外，你的 agent 可能会建一两个它自己需要的文件，比如 Claude Code 的 `.claude/` 文件夹或 `CLAUDE.md`。这些都记在 `agent-setup.md` 里。

在 Mac 访达里按 `Cmd + Shift + .` 可以看到隐藏文件夹。

## 语言

- **回复语言**：中文、英文，或者跟着你每句话的语言走。随时说一句就能换。
- **存储语言**：数据文件里字段的写法，第一次设置时定下来就固定。你写的任务名、点子、感想保持原话，不会被翻译。
- 想把存储语言整体换掉，说"把数据转成英文"或"转成中文"，它会把所有文件改写一遍。

## 连接 Google 日历

不同 agent 连接方式不一样，下面是两个例子。具体以你那个工具的官方说明为准。

**Claude Code**：需要付费的 Claude 账号，并用这个账号登录 Claude Code。在网页版或桌面版 Claude 的设置里，找到连接器页面，添加 Google Calendar 并授权。回到 Claude Code，输入 `/mcp`，确认已连接。

**Gemini CLI**：安装 Google 官方的 Workspace 扩展：
```
gemini extensions install https://github.com/gemini-cli-extensions/workspace
```

**其他 agent**：找它的扩展、插件或 MCP 列表里有没有 Google Calendar。

连好后说"同步日历"，它会把之前记下的提醒补上。以后有具体时间、有提醒、或者必须且有截止日的任务，会自动同步。手机上装了 Google 日历就会按时弹通知。

- 哪些任务自动提醒，在 `config.md` 的 `auto_remind` 里调。
- 第一次建事件时，agent 可能会问你是否允许使用日历工具。选总是允许，以后就不会再问。
- 不想同步，把 `config.md` 里的 `sync_google_calendar` 改成 `no`。
- 没连接也能正常用，提醒会先记在任务里。

## 升级

1. 先备份整个文件夹。
2. 用新版的 `README.md`、`README.en.md`、`INSTALL.md`、`AGENTS.md` 和 `.agents/` 覆盖旧的。
3. 不要覆盖你的数据文件和 `config.md`。
4. 对 agent 说"重新跑一遍 INSTALL.md"，它会更新自己那份技能副本。

## 隐私

- 所有数据都存在你电脑上的这个文件夹里。
- 助理只会改动它自己建的日历事件，不会碰你其他的日程。
- 对话内容会发给你所用 agent 背后的 AI 服务商处理，和你平时用这个工具一样。
