# 目标分层

我想规划的时候往往是一时兴起，话会比较散。你的工作是把它理成四层，并且连到具体的任务上。

## 第一步：准备

1. 运行 `date "+%Y-%m-%d %A %H:%M"`，算出当前的年、季度、月、ISO 周。
2. 读 `goals.md`、`tasks.md`、`ideas.md`。

## 第二步：判断我要做什么

- **新增规划**：我在说新的想法、新的方向。
- **调整**：我在说某个已有目标要升级、降级、搁置、放弃或改内容。
- **查看**：我只是问"我的目标是什么"。直接用第五步的格式展示，不改任何东西。

## 第三步：新增规划

### 把每个想法放进合适的层

- 一年才能看出结果的方向 → 年度
- 三个月内能达到的结果 → 季度
- 这个月能完成的 → 月度
- 下周要推进的具体重点 → 本周重点

判断不了时，默认放在月度，并问我。

### 往上连、往下拆

- **往上连**：新目标如果明显服务于某个更高层的目标，填 `上级:`。
- **往下拆**：月度和本周重点的目标，各给出 1 到 3 个可以马上开始的任务建议。任务要具体到一次能做完，例如"列出 10 个目标实验室"，而不是"找工作"。

### 控制数量

某一层超过 3 个时，提醒我一句："本月已经有 4 个目标了，要不要挑一个先放到季度？"只提醒，不强制。

### 来自点子库的

ideas.md 里如果有和新目标相关的点子，顺便问我要不要一起纳入。纳入的从 ideas.md 删掉。

## 第四步：调整

| 我说的 | 你做的 |
|---|---|
| 升级（"这个月就做"） | 移到更近的一层，并给出任务建议 |
| 降级（"先放到下个季度"） | 移到更远的一层；挂在它下面的任务，问我要不要一起推后 |
| 搁置 | 状态改成`搁置`，留在原层 |
| 放弃 | 写进 goals-archive.md（文件不存在就新建，第一行写标题（中文存储 `# 目标存档`，英文存储 `# Goal archive`），最新的写在标题下面最上面。）标 ✗，从 goals.md 删掉；挂在它下面的任务，问我怎么处理 |
| 完成 | 写进 goals-archive.md 标 ✓，从 goals.md 删掉 |

## 第五步：给我检查

用树形展示改动后的完整结构，新增或改动的标 ✦：

```
年度
  · 在纽约找到稳定的研究工作
季度 Q4
  · 拿到至少一个研究岗 offer
月度 10月
  · ✦ 投出 10 份申请 | 衡量:10 份已提交
本周重点 W43
  · ✦ 准备好简历和 cover letter 模板

建议加进任务：
  · 列出 10 个目标实验室（本周，打算）
  · 改简历第二版（本周，必须）

没问题回"好"，有要改的直接说。
```

示例只用来说明格式，实际内容按我说的来。

## 第六步：写入

我确认后：
1. 改 `goals.md`。
2. 我同意的任务建议，按 capture skill 的格式写进 `tasks.md`，并填上 `目标:` 字段。
3. 回复一句"存好了"。
