> 语言：回复用 config.md 的显示语言，写入文件用存储语言。下面示例是中文写法，存储语言为英文时按 AGENTS.md 对照表替换。

# 回顾

整个过程控制在五分钟左右。先给我看总结，再一起定下周。不要评价我做得好不好，只陈述事实。

## 第一步：准备

1. 运行 `date "+%Y-%m-%d %A %H:%M"`，算出本周的 ISO 周和日期范围（周一到周日）。
2. 读：
   - `journal/` 里覆盖本周日期的文件
   - `tasks.md`、`goals.md`、`habits.md`
   - `experiences.md` 的"已体验"
   - `ideas.md`
   - `learning/` 里所有状态为"进行中"的档案
   - `projects/` 里所有状态为"进行中"的档案
   - `config.md`

如果今天是周一到周三，回顾的是**上一周**；周四到周日，回顾的是**本周**。

## 第二步：本周总结

按下面的格式，只列有内容的部分：

```
W42 回顾（10/13 到 10/19）

完成 12 件：必须 4，打算 6，有空 2
放弃 1 件：整理邮件

一直在推的：
  · 健身（顺延 3 次）
  · 洗车（顺延 2 次）

习惯：
  · 健身 1/3 次
  · 阅读 5/7 天

新体验：电影《魔女嘉莉》，专辑 xx

项目：
  · 小说xx 推进 3 次 | 24000/80000 字，本周 +6000
  · 桌游 本周没动（上次 09-30）

学习：
  · 拳击 练了 3 次（共 12 次）| 基础
  · 画画 本周没练（上次 10-05）
  📚 可以复盘：拳击

本周重点：
  ✓ 准备好简历模板
  ◐ 投出 3 份申请（完成 1 份）

目标进展：
  · 投出 10 份申请：本周推进 2 个任务
  · 拿到研究岗 offer：本周没有相关任务
```

数据来源：
- **完成和放弃**：journal 里本周的 ✓ 和 ✗。必须度看 journal 行末的括号。
- **一直在推的**：tasks.md 里顺延 ≥ 2 的。
- **习惯**：habits.md 里本周的打卡次数，对比目标。
- **新体验**：experiences.md 已体验里本周日期的条目。
- **项目**：每个进行中的档案，数本周的进展记录条数。有进度指标的，算出本周增量。
- **学习**：每个进行中的档案，数本周的练习记录条数。"下次复盘"已到的，列在"可以复盘"里。
- **本周重点**：goals.md 的"本周重点"逐条判断：✓ 完成、◐ 部分、✗ 没做。
- **目标进展**：月度目标，看本周完成的任务里有多少带对应的 `目标:` 字段。没有进展的也列出来。

## 第三步：定下周

按顺序，一次只问一件：

**1. 一直在推的事**
如果有顺延 ≥ 2 的，问我每件怎么办：拆小、降到本月、放弃、还是下周一定做。

**2. 下周重点**
先给我建议，最多 3 条，来源依次是：
- 下周有截止日的必须任务
- 本周没有进展的月度目标
- tasks.md 里"做"在下周的事

然后问："下周最想推进的是哪 1 到 3 件？可以直接用我的建议。"

**3. 升降级**
看一眼 tasks.md 里"做"在本月、近期的事，以及点子库里加入超过一个月的点子。挑出 1 到 3 条问我：要不要提前到下周，或者干脆删掉。没有合适的就跳过这一步。

**4. 项目**
- 每个进行中的项目，问一句下周的下一步是什么（已经有没打勾的下一步就直接给我看，问要不要换）。我说了就写进档案的"下一步"。
- 问我要不要把哪个项目的下一步放进下周重点或下周的任务。
- 超过两周没进展的项目：问一句继续、暂停还是放弃。

**5. 学习**
- 有到期复盘的技能：问我现在要不要顺便复盘，两分钟。要的话按 learn skill 的"复盘"做，不要的话跳过。
- 超过三周没练的技能：问一句要继续、暂停还是放弃。
- 点子库里标了 `备注:学习` 的点子，如果加入超过一个月，可以问一句要不要开始学。

## 第四步：月度、季度、年度回顾

**判断条件**：下一周的周一，如果已经进入新的月份，就顺带做月度回顾。同理，进入新季度做季度回顾，进入新年做年度回顾。层级越高越简短。

月度回顾在周回顾之后追加：
1. 本月目标逐条：✓ / ◐ / ✗。
2. 问我：没完成的，挪到下个月、降到季度、还是放弃？
3. 问我："下个月最想做到的 1 到 3 件事？"可以从季度目标里挑。

季度和年度回顾同理，只是看的层级更高。

## 第五步：写入

我确认后：
1. **存档**：把已结束周期的本周重点（以及月度、季度、年度目标，如果做了对应回顾）连同 ✓ ◐ ✗ 结果，写到 `goals-archive.md` 最上面。文件不存在就新建，第一行写标题（中文存储 `# 目标存档`，英文存储 `# Goal archive`），最新的写在标题下面最上面。
2. **更新 goals.md**：清空已结束的周期，写入新的本周重点（以及新的月度等）。
3. **更新 tasks.md**：按第三步的决定修改"做"字段、删除放弃的任务（放弃的写进 journal）。下周重点如果还没有对应任务，按 capture 格式新建。
4. **写回顾记录**：在 journal 当月文件里，加一个 `## W42 周回顾` 小节，放第二步的总结和下周重点。
5. **更新 state.md**：`last_review` 改成今天。
6. 如果改动了带日历事件的任务，按 calendar skill 同步。

最后回复：

```
回顾存好了。下周重点：
  · xx
  · xx
```

## 中途离开

我中途不想继续了，就把已经确认的部分写入，没确认的不动。`last_review` 照样更新，免得每天被提醒。
