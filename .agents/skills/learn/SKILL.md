> 语言：回复用 config.md 的显示语言，写入文件用存储语言。下面示例是中文写法，存储语言为英文时按 AGENTS.md 对照表替换。

# 学习

这里记的是应用型的技能，比如拳击、画画、写小说、上网课。目的是留下一条学习曲线，不是帮我背书备考，所以**没有复习提醒，也不排复习任务**。

只有一个定期的**复盘**：隔一段时间回头看看学到哪了、卡在哪、下一步练什么。

学技能和别的事不一样：
- 不像**习惯**，只看有没有打卡。学习要看学到了哪一步。
- 不像**体验**，做一次就算完。学习有开始、有过程、有阶段。
- 不像**点子**，只是想想。学习一旦开始，就要有记录。

每个技能一个文件，放在 `learning/` 文件夹里，文件名用技能名，例如 `learning/拳击.md`。

## 准备

1. 运行 `date "+%Y-%m-%d %A %H:%M"`。
2. 列出 `learning/` 里的文件，读和我说的技能相关的那个。

## 模式一：开始学

我说"想学 xx"时，先判断我是真的要开始，还是只是想想：
- **只是想想**（"有空想学画画"、"以后想学"）：放进 ideas.md，加 `备注:学习`。不建档案。
- **要开始了**（"开始学"、"报了课"、"这周开始练"）：建档案。
- **拿不准**：问一句"现在就开个学习档案，还是先放点子库？"

建档案时，最多问两个问题，都能跳过：

```
开个"拳击"的学习档案。两个问题，不想答可以跳过：

1. 学到什么程度算会了？比如"能打完一套组合"、"能实战三回合"。
2. 有没有几个想经过的里程碑？我也可以帮你列。

复盘默认每月一次，想改可以说"拳击每两周复盘"。
```

然后从 `.agents/templates/<存储语言>/learning-skill.md` 读出模板，填好写进 `learning/技能名.md`。
- 我没给里程碑时，根据技能常识建议 3 到 5 个，标注"建议"，我确认后再写。
- 状态设为 `进行中`，阶段设为 `入门`。
- 复盘频率用 config.md 的 `default_retro_every`，除非我另外说了。
- 下次复盘 = 开始日期 + 复盘频率。

如果我同时提到了固定的上课时间（"每周二四上课"），那是我自己安排的日程，按 capture skill 的格式在 tasks.md 里建任务，加 `标签:学习:技能名` 和对应的 `重复:`。这是我要求的，不是系统自动加的。

## 模式二：记录练习

我说"今天练了 xx"、"上了 xx 课，学了 yy"时：

1. 在档案的"练习记录"最上面加一行：
   ```
   - 2026-10-14 | 学了刺拳和后手直拳的组合 | 60分钟
   ```
   时长不知道就不填。我只说"练了"没说内容，就问一句"练了什么？"，我不想说就写"练习"。
2. 如果这次练习明显完成了某个里程碑，问我要不要打勾。
3. 在 journal 当天写一行（格式同 done skill，括号里写 `学习`）。
4. 如果 tasks.md 里有对应的 `学习:技能名` 任务，按 done skill 处理那条任务。

**记录练习时绝对不要做的事**：
- 不改"下次复盘"日期。
- 不在 tasks.md 里新建任何任务。
- 不建任何日历事件。

回复一句话，带上总次数：

```
✓ 拳击练习记好了，这是第 7 次。
```

## 模式三：复盘

### 什么时候触发

- 档案的"下次复盘"到了。**只在应用内提一句，不建日历事件，不建任务。** now skill 会在"今天要干嘛"末尾提，周回顾也会提。我不理它也没关系。
- 我主动说"复盘一下 xx"。

### 怎么复盘

花两分钟回头看。先给我看这段时间的数据，再问问题，一次一个：

```
拳击复盘（上次复盘 9/28，到今天一个月）
这段时间练了 9 次，完成了 1 个里程碑：三拳组合。

1. 这段时间最大的进步是什么？
2. 卡在哪了？
3. 下一阶段想重点练什么？
4. 你觉得现在在哪个阶段：入门、基础、熟练、掌握？
```

问完后：
1. 在"复盘记录"最上面加一行：
   ```
   - 2026-10-28 | 进步:组合拳连贯了；卡住:步法；下一步:防守 | 阶段:基础
   ```
2. 阶段有变化的，更新档案顶部的"阶段"。
3. 我说的内容如果对应某个里程碑，问我要不要打勾。
4. 下次复盘 = 今天 + 复盘频率。
5. 如果我觉得已经掌握了，问我："要把状态改成掌握吗？"改了之后不再提复盘。

我只回答了一两个问题就不想继续，就按已回答的部分记录，照样更新下次复盘日期。

### 改复盘频率

我说"拳击改成每两周复盘"、"画画两个月复盘一次"时：
1. 改档案里的"复盘频率"。可选：每周、每两周、每月、每两个月、每季度。
2. 下次复盘 = 上次复盘日期（没有就用开始日期）+ 新频率。如果算出来早于今天，就设为今天。
3. 回一句确认。

我说"所有技能都改成每两周复盘"，改 config.md 的 `default_retro_every`，并问我要不要把现有档案一起改。

## 模式四：看学习曲线

我问"我学得怎么样"、"学习进度"时：

**问所有技能**：

```
正在学
  · 拳击 | 基础 | 共 12 次 | 上次练 10-26 | 复盘 11-28
  · 画画 | 入门 | 共 3 次 | 上次练 10-05 ⚠️ 三周没练了

暂停：小说写作
已掌握：（无）
```

**问某一个技能**，给一条简单的曲线：

```
拳击 · 2026-09-28 开始 · 现在：基础

每周练习次数
  W40 ██ 2
  W41 ███ 3
  W42 █ 1
  W43 ███ 3

阶段变化：入门（9/28）→ 基础（10/26）
里程碑：3/5 完成
  ✓ 站姿和步法
  ✓ 刺拳和后手直拳
  ✓ 三拳组合
  ○ 防守和闪躲
  ○ 实战一回合
```

条形图里每个 █ 代表一次练习，从"练习记录"按 ISO 周统计。没练习的周也要显示，写 `0`。

## 暂停和放弃

- **暂停**：我说"先不学了，以后再说"。状态改成 `暂停`，不再提复盘。
- **放弃**：我说"不学了"。状态改成 `放弃`。档案保留，不删除，这也是记录的一部分。
- **恢复**：我说"重新开始学 xx"。状态改回 `进行中`，下次复盘从今天重新算。

## 和其他功能的关系

- 想把练习变成固定节奏（"每天画 15 分钟"），可以同时在 habits.md 建一个习惯。两边各记各的，不冲突。
- 学习可以挂在 goals.md 的目标下面。档案顶部的"目标"字段填目标名。
- 要备考、背单词这种需要按遗忘曲线复习的，不适合用这里，建议用专门的工具。
