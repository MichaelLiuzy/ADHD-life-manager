> 语言：回复用 config.md 的显示语言，写入文件用存储语言。下面示例是中文写法，存储语言为英文时按 AGENTS.md 对照表替换。

# 收录

## 第一步：准备

1. 运行 `date "+%Y-%m-%d %A %H:%M"`，记下今天日期、星期和当前时间。
2. 读 `tasks.md`、`ideas.md`、`experiences.md`、`habits.md`，用来查重和匹配习惯名称。

## 第二步：拆分

把我说的话拆成一条条独立的事。一句话里有两件事，就拆成两条。

## 第三步：判断去向

每一条按下面的顺序判断，命中就停：

1. **已经做完的事**（"刚看完"、"昨天去了"）：不在这里处理，转交 done skill。练习了某个在学的技能（"今天练了拳击"），转交 learn skill。
2. **项目相关**：要开始一个长期项目（"开始写小说"、"开了个新项目"），或者汇报某个已有项目的进展（"小说今天写了 2000 字"），转交 project skill。
3. **要开始学某个技能**（"开始学画画"、"报了拳击课"）：转交 learn skill 建档案。只是"以后想学"的，按第 6 条进点子库，加 `备注:学习`。
4. **有时间打算或截止日的事**：进 `tasks.md`。
5. **书、电影、剧、专辑、演出、城市，且没有时间打算**：进 `experiences.md` 的"想体验"。
6. **其他没有时间打算的想法**：进 `ideas.md`。

注意：书影剧这类如果有截止日或明确时间（"周六前看完"），走第 4 条进 tasks，并加标签 `体验:类型`。和某个学习档案相关的任务（"周四上拳击课"），加标签 `学习:技能名`。属于某个项目的任务（"周末改小说大纲"），加标签 `项目:项目名`。

## 第四步：填字段

**必须度**，根据我的用词判断：
- `必须`：一定、必须、得、务必、不能忘、有明确后果。
- `打算`：准备、打算、要、今天去、下午去。
- `有空`：有空、看情况、不确定、可能、想。

英文对照：
- must：have to, must, need to, can't forget, has to be done by, otherwise.
- plan：going to, planning to, will, gonna, this afternoon.
- maybe：if I have time, maybe, not sure, might, would like to, I want to.

时间词英文对照：today、tomorrow、by Saturday（截止）、next week、this month、end of the year。"by Saturday" 指本周六，今天已过周六则指下周六。

**做**：把"今天、明天、周六、下周、这个月、年底"换算成 AGENTS.md 规定的写法。"下午"、"晚上"这类时段保留。

**截止**："之前"、"截止"、"最晚"后面的日期。"周六之前"指本周六，若今天已过周六则指下周六。

**重复**：常见的周期性事务（房租、账单、订阅）可能重复。不确定时作为问题问我，不要自己假设。

**习惯标签**：如果事情名称和 habits.md 里的习惯对得上，加 `标签:习惯:名称`。

**目标**：如果这件事明显服务于 goals.md 里的某个目标，填 `目标:名称`。拿不准就不填，不用问。

**提醒**：我说了"提醒我"就填具体时间。没说具体时间的（"记得提醒我交房租"），按常识选一个时间：有截止日的放在截止前一天的 `deadline_reminder_time`，没有的放在"做"那天早上 9 点。

另外，按 config.md 的 `auto_remind`，有具体钟点的任务、必须且有截止日的任务，会自动建提醒，不用问我。在第五步的检查清单里用 ⏰ 标出哪些会建提醒，我不想要可以直接说。

## 第三步半：长期规划转交

如果我说的主要是方向性的规划（"今年想""这个季度要"），而不是具体的事，转交 goals skill 处理。混在一起说的，具体的事按本 skill 处理，规划部分转交 goals。

## 第五步：给我检查

用下面的格式一次性展示，不要逐条问：

```
今天
  必须：交房租
  打算：下午买菜、洗衣服
  有空：健身
本周
  必须：看完魔女嘉莉（周六截止）⏰ 周五 9:00
想体验
  书：昨天看到的那本
  电影：AMC 新片
点子库
  （无）

❓ 交房租是每月固定的吗？几号？
❓ 那本书叫什么？不知道也行，先记成"昨天看到的书"。

没问题回"好"，有要改的直接说。
```

规则：
- 只展示有内容的分组。
- 拿不准的地方用 ❓ 标出来，最多三个。拿得准的不要问。
- 发现和已有条目重复，在末尾提一句"这条已经在 xx 里了"，不重复添加。

## 第六步：写入

我回复确认后：
1. 按 AGENTS.md 的格式写进对应文件。
2. **立刻运行 calendar skill**，为所有标了 ⏰ 的任务建日历事件。这一步不能省，也不能留到以后。
3. 回复一句"存好了"，再附上今天剩余的安排（格式同 now skill 的"今天要干嘛"）。末尾一行说明日历变动，例如"已加到日历：看完魔女嘉莉（周五 9:00 提醒）"。日历没连上的，按 calendar skill 的说法讲清楚。

如果我只改了其中几条，改完直接写入，不用再完整确认一遍。
