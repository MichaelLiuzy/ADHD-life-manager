> 语言：回复用 config.md 的显示语言，写入文件用存储语言。下面示例是中文写法，存储语言为英文时按 AGENTS.md 对照表替换。

# 项目

项目是一件要做很久、有明确产出的事。写一部小说、做一个 app、设计一款桌游、搬家、准备一次申请季，都是项目。

它和别的东西的区别：
- **任务**做一次就完。项目由很多任务组成。
- **目标**是想达到的结果（"今年出版一部小说"）。项目是实际在做的那件事（"写《xx》"）。项目可以挂在目标下面。
- **学习**的产出是自己会了一个技能。项目的产出是一个东西。

每个项目一个文件，放在 `projects/` 文件夹里，文件名用项目名，例如 `projects/小说xx.md`。

## 准备

1. 运行 `date "+%Y-%m-%d %A %H:%M"`。
2. 列出 `projects/` 里的文件，读和我说的项目相关的那个。

## 模式一：建项目

我说"开了个项目"、"开始写小说"、"要做一个 xx"时：
- **只是想想**（"以后想写本小说"）：放进 ideas.md。不建档案。
- **要开始了**：建档案。
- **拿不准**：问一句"现在就建个项目档案，还是先放点子库？"

建档案时，最多问三个问题，都能跳过：

```
建个"小说xx"的项目档案。三个问题，不想答可以跳过：

1. 做到什么程度算完成？比如"写完初稿"、"上架 App Store"。
2. 有没有想用一个数字追踪进度？比如字数、章节数、页数。
3. 第一步打算做什么？
```

然后从 `.agents/templates/<存储语言>/project.md` 读出模板，填好写进 `projects/项目名.md`。
- 状态设为 `进行中`。
- 我没给里程碑时，根据项目类型建议 3 到 5 个，标注"建议"，我确认后再写。
- 我说了进度指标（例如"字数，目标 8 万"），填进"进度指标"。没说就留空，以后随时能加。
- "下一步"里写 1 到 3 条。我说的第一步写进去；我没说，就根据里程碑建议一条。

如果项目在 goals.md 里有对应的目标，填"目标"字段，并顺便问一句。

## 模式二：记进展

我说"今天小说写了 2000 字"、"app 的登录页做完了"、"桌游测试了一轮"时：

1. 在档案的"进展记录"最上面加一行：
   ```
   - 2026-10-14 | 写完第三章，主角第一次见到反派 | 进度:24000
   ```
   有进度指标的，记下当前的累计值。我说的是增量（"写了 2000 字"），就在上一次的累计值上加。不知道上次的值，就问我一句。
2. 我做的事对应"下一步"里的某一条，打勾，问我新的下一步是什么。我不说就先空着。
3. 对应某个里程碑，问我要不要打勾，打勾时写上日期。
4. 在 journal 当天写一行（格式同 done skill，括号里写 `项目`）。
5. tasks.md 里有对应的 `项目:名称` 任务，按 done skill 处理那条任务。

回复一句话：

```
✓ 小说xx 记好了。现在 24000 / 80000 字，30%。
```

**记进展时不要做的事**：不建日历事件，不自动在 tasks.md 里建任务。

## 模式三：下一步

我问"小说下一步做什么"、"xx 项目接下来干嘛"时：
1. 列出档案里没打勾的"下一步"。
2. 一条都没有时，看最近一个没完成的里程碑，建议 1 到 3 条具体的下一步，我确认后写入。
3. 问我要不要把其中某条放进今天或本周的任务。要的话，按 capture 的格式写进 tasks.md，加 `项目:项目名` 标签。

"下一步"要具体到一次能做完。"写小说"不行，"写第四章开头的对话"可以。

## 模式四：看项目

我问"我的项目"、"项目进展怎么样"时：

**问所有项目**：

```
进行中
  · 小说xx | 24000/80000 字 30% | 上次推进 10-14 | 下一步：写第四章开头
  · 桌游 | 里程碑 2/5 | 上次推进 09-30 ⚠️ 两周没动了

暂停：app 重构
已完成：（无）
```

**问某一个项目**：

```
小说xx · 2026-09-01 开始 · 进行中
完成标准：写完初稿
进度：24000 / 80000 字（30%）

每周推进次数
  W40 ██ 2
  W41 ███ 3
  W42 0
  W43 █ 1

里程碑 2/5
  ✓ 大纲（09-10）
  ✓ 前三章（10-14）
  ○ 中段转折
  ○ 结局
  ○ 初稿修改

下一步
  ○ 写第四章开头的对话
```

每周推进次数从"进展记录"按 ISO 周统计，没推进的周写 `0`。

## 状态变化

- **暂停**：我说"先停一停"。状态改成 `暂停`，周回顾不再追问。
- **完成**：我说"做完了"、"初稿写完了"且对应完成标准。状态改成 `完成`，写上完成日期。在 journal 写一行 `✓ 完成项目：名称`。如果对应 goals.md 里的目标，问我要不要一起标完成。
- **放弃**：状态改成 `放弃`。档案保留，不删除。
- **恢复**：状态改回 `进行中`。

## 和其他功能的关系

- 项目里程碑上写的日期只是自己的计划，不进日历。真正要提醒的事，以任务的形式放进 tasks.md，按 calendar skill 的规则处理。
- 项目档案可以有一个"笔记"小节，放设定、灵感、待解决的问题。我说"小说记一下，反派的动机要改"，就加进笔记，不算进展。
