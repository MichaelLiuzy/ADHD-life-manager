# 顺延

有两种情况会用到这个 skill。

## 情况一：每天第一次对话时的检查

### 找出过期的事

运行 `date "+%Y-%m-%d %A %H:%M"`，读 `tasks.md`。下面这些算过期：
- 做 = 某天，且早于今天。
- 做 = 某周、某月、某季度，且那个范围已经整个过去了。

另外单独找出：截止日已经过了的事。

没有任何过期的事：直接把 `state.md` 的 `last_check` 改成今天，然后正常回应我。不用告诉我检查过了。

### 问我怎么处理

一次性列出来，给一个默认选项让我一个字就能回：

```
昨天有 3 件没做完：
  · 洗衣服（打算）
  · 健身（有空）
  · 整理邮件（打算，已顺延 3 次）

⚠️ 截止已过：交房租（截止 10-14）

默认都挪到今天，回"好"就行。
想换的直接说，比如"健身放弃"、"邮件挪到周末"。
```

可选的处理方式：
- **挪到今天**：做 改成今天。
- **改到某天**：做 改成那天。
- **降级**：做 改成本周或本月。
- **放弃**：从 tasks.md 删除，在 journal 当天写一行 `- ✗ 名称（放弃）`。

### 顺延满三次的特殊处理

一件事的"顺延"达到 3 次时，不要默认挪到今天。单独问：

```
"整理邮件"已经挪了 3 次。要不要：
  1. 拆小一点，先做其中一部分
  2. 降到本月，不放在每天
  3. 放弃
```

### 收尾

1. 每挪动一次，"顺延"加 1。
2. 截止已过的事，提醒我一句，按我的回复处理。
3. 改动的任务里有 `日历:` 字段的，按 calendar skill 同步。
4. 把 `state.md` 的 `last_check` 改成今天。
5. 处理完后，接着回应我这次本来要说的事。

## 情况二：我说"今天不行了"

目的是给今天减负，不是追问原因。

1. 读今天的任务。
2. 只留一件：截止今天的必须；没有的话，留最小最容易的一件必须；也没有就一件都不留。
3. 其余的按默认方案挪：必须挪到明天，打算挪到本周，有空挪到本周。
4. 给我看方案：

```
好，今天只留一件：交房租。
其余挪走：
  · 买菜、洗衣服 → 明天
  · 健身 → 本周

回"好"就这样定了。
```

5. 我确认后写入，有 `日历:` 字段的按 calendar skill 同步。这种主动减负不增加"顺延"次数。
