> 语言：回复用 config.md 的显示语言，写入文件用存储语言。下面示例是中文写法，存储语言为英文时按 AGENTS.md 对照表替换。

# 完成

## 第一步：找到对应的事

1. 运行 `date "+%Y-%m-%d %A %H:%M"`。
2. 在 `tasks.md` 里找我说的那件事。名称可以模糊匹配。
3. 匹配到多条，或完全找不到，先问我。
4. 我说的事不在 tasks 里也没关系（比如临时看了一部电影），照样记录，只是跳过第二步。

## 第二步：更新 tasks.md

- **没有重复字段的**：删掉这一行。
- **有重复字段的**：不删。把"做"改成下一次的日期，"顺延"清零。如果有"提醒"，也按同样间隔往后挪。

## 第三步：写日志

写进 `journal/YYYY-MM.md`（当月文件，不存在就新建，标题为 `# YYYY年M月`）。

按天分组，最新的一天写在最上面：

```
## 10-14 周三
- 14:35 ✓ 交房租（必须）
- 11:20 ✓ 洗衣服（打算）
```

同一天里，新完成的写在该日分组的最上面。行末括号写必须度，周回顾要用。不在 tasks 里的临时事项，括号写"临时"。

如果任务有 `目标:` 字段，在括号里一并写上，例如 `（必须，目标:投出10份申请）`。

## 第三步半：同步日历

任务有 `日历:` 字段的，按 calendar skill 的规则处理：没到时间的事件删除，重复任务为下一次新建事件。

## 第四步：按标签分发

**标签是 `体验:类型`**，或者事情本身是书、电影、剧、专辑、演出、旅行：
1. 如果 `experiences.md` 的"想体验"里有这一条，删掉。
2. 在"已体验"最上面加一行。
3. 顺口问一句"一句话感想？"。我回了就补上，没回或说算了就不填。只问一次。

**标签是 `习惯:名称`**，或者我说的事和 habits.md 里的某个习惯对得上：
在 `habits.md` 的"打卡"里，当月分组下加一行 `- MM-DD 名称`。当月分组不存在就新建，放在最上面。

**标签是 `学习:技能名`**，或者我说的事是练习 `learning/` 里某个在学的技能：
按 learn skill 的"记录练习"处理，在档案里加一条练习记录。journal 里只写一行，不重复写。

**标签是 `项目:项目名`**，或者我说的事是推进 `projects/` 里某个项目：
按 project skill 的"记进展"处理，加一条进展记录，对应的"下一步"打勾。journal 里只写一行，不重复写。

## 第五步：回复

一句话确认，加上今天还剩多少：

```
✓ 交房租，记好了。今天还剩打算 2 件，有空 1 件。
```

如果今天的必须和打算都做完了，可以说一句"今天该做的都做完了"。不要夸张地庆祝。
