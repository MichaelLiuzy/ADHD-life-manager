> 语言：回复用 config.md 的显示语言，写入文件用存储语言。下面示例是中文写法，存储语言为英文时按 AGENTS.md 对照表替换。

# 现在干嘛

## 准备

1. 运行 `date "+%Y-%m-%d %A %H:%M"`。
2. 读 `tasks.md`。需要时再读 `ideas.md`、`experiences.md`、`habits.md`。
3. 按 AGENTS.md 的规则，把任务算进"今天、本周、本月、近期、长期"。

## 模式一："现在干嘛"

只建议一件事。挑选顺序：
1. 截止日就是今天的`必须`。
2. 时段是现在的（例如现在是下午，挑做="今天 下午"的）。
3. 其余今天的`必须`。
4. 今天的`打算`。
5. 今天的`有空`。
6. 今天都做完了：从本周的事、进行中项目的"下一步"或点子库里挑一件，并说明这是额外的。

同一级里有多件时，挑耗时短、容易开始的那件。

回答格式：

```
现在 14:20。建议去买菜。

今天还剩：必须 1 件，打算 2 件，有空 1 件。
想看全部就说"今天"。
```

## 模式二："今天要干嘛"

```
10月14日 周三，现在 14:20

必须
  · 交房租
打算
  · 买菜（下午）
  · 洗衣服
有空
  · 健身

⏰ 7天内截止：看完魔女嘉莉（周六）
```

规则：
- 只列没做完的。
- 空的分组不显示。
- 今天全部做完时，说一句"今天的都做完了"，再问要不要看本周的。

## 模式三："这周"、"这个月"、"全部"

按时间范围分组，每组只列名称和必须度：

```
本周：看完魔女嘉莉（必须）
本月：……
近期：……
长期：……
点子库：5 条（说"点子"看全部）
想体验：书 2、电影 3、城市 1
```

问"点子库"或"想体验"时，再完整列出那个文件的内容。

## 模式四："我的目标"

读 goals.md，按年度、季度、月度、本周重点的树形列出，每个目标后面标上本周有几个相关任务完成（从 journal 里数）。只读不改，要调整转交 goals skill。

## 今天视图里带上本周重点

"今天要干嘛"的末尾，如果 goals.md 有本周重点，加一行：

```
🎯 本周重点：准备简历模板、投 3 份申请
```

## 今天视图里带上该复盘的技能

读 `learning/` 里状态为"进行中"的档案。"下次复盘"在今天或之前的，在"今天要干嘛"末尾加一行：

```
📚 可以复盘了：拳击（说"复盘拳击"，两分钟）
```

超过三周没有练习记录的，也可以顺带提一句，例如"画画三周没练了"。每个技能一周最多提一次，不要天天念。

## 模式五："学习进度"

转交 learn skill 的"看学习曲线"。

## 模式六："我的项目"

转交 project skill 的"看项目"。

## 今天视图里带上停滞的项目

进行中的项目超过两周没有进展记录的，在"今天要干嘛"末尾提一句，例如"🛠 桌游两周没动了，下一步是：做第二版卡牌"。每个项目一周最多提一次。

## 不要做的

- 不要一次列出所有内容，除非我要求。
- 不要评价我今天做了多少。
- 只读不改。我在这里说"做完了"，转交 done skill。
